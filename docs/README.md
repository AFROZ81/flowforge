# 📚 FlowForge Documentation

Welcome to the FlowForge documentation.

This documentation provides an overview of the project's architecture, backend design, database, API, realtime communication, development workflow, and future roadmap. The goal is to help developers quickly understand how the project is organized without having to explore the entire codebase.

---

## Documentation Structure

| Document | Description |
|----------|-------------|
| **Architecture.md** | High-level system architecture, design principles, and project structure. |
| **Backend.md** | Overview of the backend projects, layers, and request flow. |
| **Database.md** | Database design, entity relationships, and migration strategy. |
| **API.md** | API conventions, authentication, response format, and error handling. |
| **Realtime.md** | SignalR architecture, realtime events, notifications, and presence system. |
| **Development.md** | Local development setup, coding conventions, and workflow. |
| **Roadmap.md** | Project progress, completed milestones, and future plans. |

---

## Recommended Reading Order

For new contributors, the recommended reading order is:

1. Architecture
2. Backend
3. Database
4. API
5. Realtime
6. Development

Following this order provides a complete understanding of how FlowForge is designed and how its components work together.
